User Flow
User arrives at the Landing Page and proceeds to the Dashboard.

User clicks "Add New Farm" and fills out the technical specifications (Soil type, acreage, irrigation method, region).

User navigates to "Generate Advisory", selects a saved farm, inputs current season/budget, and clicks "Analyze".

The backend constructs a dense prompt, queries Gemini via @google/genai, and parses the JSON response.

The user is redirected to the /advisory/:id page to view the formatted, interactive agronomic report.

Database Schema
Use the following production SQL schema to initialize the Replit Postgres database. Execute these using standard pg client queries in your backend initialization step.

SQL
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    email VARCHAR(255) UNIQUE NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE farms (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    name VARCHAR(255) NOT NULL,
    region VARCHAR(255) NOT NULL,
    area_acres NUMERIC(10, 2) NOT NULL,
    soil_type VARCHAR(100) NOT NULL,
    irrigation_method VARCHAR(100) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE advisories (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    farm_id UUID REFERENCES farms(id) ON DELETE CASCADE,
    target_season VARCHAR(100) NOT NULL,
    budget_level VARCHAR(50) NOT NULL,
    ai_raw_response JSONB NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
Row Level Security (RLS) / Data Isolation Rules
Since we are using standard Node.js with Postgres, enforce data isolation at the API level.

Every API request must include a x-user-id header (for this MVP, acting as our auth token).

All SELECT, UPDATE, and DELETE queries on farms and advisories MUST include a WHERE user_id = $1 or a JOIN to verify ownership.

Under no circumstances should User A be able to query or view an advisory linked to a farm owned by User B.
